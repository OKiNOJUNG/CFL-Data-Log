# ADR-0001: สูตรนับเซลล์และการเก็บค่าดิบ

- **สถานะ:** ยอมรับแล้ว
- **วันที่:** 2026-10-06

## บริบท
ในตัวอย่างเดิมเขียนว่า "÷ 250,000" ซึ่งคำนวณออกมาไม่ตรงกับค่าใน Excel (ประมาณ 10⁸)
และ Excel เก็บไว้แค่ผลลัพธ์สุดท้าย จึงตรวจย้อนกลับไม่ได้

## การตัดสินใจ
1. สูตร: **cells/mL = (ผลรวมค่านับ 5 ช่อง) × เท่าการเจือจาง × 250,000**
2. นับ **แยก 3 ชุด** คือ Total, Budding, Dead (ชุดละ 5 ช่อง รวม 15 ค่าต่อตัวอย่าง)
3. เก็บ **ค่าดิบทุกช่อง + เท่าการเจือจาง** ลงฐานข้อมูล ระบบคำนวณผลให้ (ผู้ใช้ไม่ต้องพิมพ์ผลเอง)
4. ค่าคงที่ 250,000 เก็บไว้เป็น config แก้ได้ในอนาคต
5. หน่วยที่แสดงคือ **cells/mL** (ไม่ใช่ CFU/mL)

## ผลที่ตามมา
- ตรวจย้อนกลับและคำนวณใหม่ได้ ถ้าภายหลังมีการแก้สูตร
- นำค่าที่คำนวณได้ไปหาอัตราส่วนได้ เช่น % Budding, % Viability = (Total − Dead) / Total
- หน้ากรอกข้อมูลมีช่องให้กรอกมากขึ้น จึงต้องออกแบบ UX บนมือถือให้กรอกเร็ว
