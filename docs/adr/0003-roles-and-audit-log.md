# ADR-0003: บทบาทผู้ใช้ (Admin) และ Data Log

- **สถานะ:** ยอมรับแล้ว
- **วันที่:** 2026-10-06

## การตัดสินใจ
### บทบาท
| บทบาท | ดูข้อมูลทุกโปรเจกต์ | จัดการโปรเจกต์ตัวเอง | แก้/ลบ ข้อมูลทุกคน | ปรับสิทธิ์ผู้ใช้ | แก้สูตรคำนวณ | ดู Data Log |
|---|---|---|---|---|---|---|
| **Researcher** | ✅ | ✅ | ❌ | ❌ | ❌ | (ของตัวเอง ❓) |
| **Admin** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ ทั้งหมด |

### Data Log (Audit Trail)
- บันทึก **ทุกครั้ง** ที่มีการ สร้าง/แก้ไข/ลบ ทั้งข้อมูลโปรเจกต์ ผลวิเคราะห์ สิทธิ์ผู้ใช้ และสูตร
- สิ่งที่บันทึก: ผู้ทำ, วัน-เวลา (server timestamp), การกระทำ, ตำแหน่งข้อมูล
  (Project/Batch/Tank/Time/Parameter), **ค่าก่อนแก้ → ค่าหลังแก้**
- Log **แก้ไขหรือลบไม่ได้** แม้แต่ Admin ก็ทำไม่ได้ (append-only) เพื่อให้ตรวจสอบย้อนกลับได้

## ผลที่ตามมา
- ใน Firestore เก็บ log ไว้ที่คอลเลกชัน `auditLogs` และใช้ rules อนุญาตเฉพาะ `create`
- การเขียน log จากฝั่ง client ยังมีความเสี่ยงว่าจะถูกข้ามได้ ถ้าต้องการให้เชื่อถือได้ 100%
  ต้องใช้ Cloud Functions ซึ่งต้องเปิดแผน Blaze (ยังจ่ายตามการใช้งาน แต่ต้องผูกบัตร) ❓ รอตัดสินใจ
