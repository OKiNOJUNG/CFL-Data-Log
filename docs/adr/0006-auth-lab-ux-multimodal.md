# ADR-0006: ระบบยืนยันตัวตน (Auth), ประสบการณ์ผู้ใช้ในแล็บ (Lab UX) และ Multimodal Feedback

- **สถานะ:** ยอมรับแล้ว
- **วันที่:** 2026-10-06

## บริบท
ข้อมูลงานวิจัยการหมักของมิตรผลเป็นข้อมูลทรัพย์สินทางปัญญาภายใน ต้องมีความปลอดภัย และการกรอกข้อมูลของนักวิจัยเกิดขึ้นในบริบทแล็บจริง (ใส่ถุงมือ, ส่องกล้องจุลทรรศน์, ยืนหน้าถังหมัก)

## การตัดสินใจ
1. **ระบบยืนยันตัวตน (Authentication):**
   - ใช้ **Email & Password** ผ่าน Firebase Auth
   - นโยบายความปลอดภัย: บัญชีนักวิจัยใหม่ต้องได้รับการ **อนุมัติหรือเชิญโดย Admin** เท่านั้น เพื่อป้องกันการเข้าถึงจากภายนอก
2. **โหมดการกรอกข้อมูลนับเซลล์ (Cell Counter Lab UX):**
   - รองรับ **2 โหมดสลับได้ทันที (Toggle):**
     1. **Quick Numpad Mode:** แป้นตัวเลขขนาดใหญ่ กรอกตัวเลขช่องที่ 1 แล้วข้ามไปช่องถัดไปอัตโนมัติ (Auto-advance) คำนวณผลรวมและ cells/mL แบบ Real-time
     2. **Microscope Tally Mode:** ปุ่มคลิกเกอร์ขนาดใหญ่ (+ / -) สำหรับกดนับเซลล์ทีละตัวขณะตากำลังส่องกล้องจุลทรรศน์ พร้อมเสียง Click สั้นๆ
3. **Multimodal Feedback (เสียง, การสั่น, แอนิเมชัน):**
   - **บันทึกสำเร็จ:** เสียง Audio chime นุ่มนวล + Haptic vibration สั้นๆ (บนมือถือ) + Toast แจ้งเตือนมุมจอ
   - **ค่าผิดปกติ (Out-of-range Warning):** แสดง Inline message สีส้ม/แดงใต้ช่องกรอก (เช่น Brix ติดลบ, % Budding > 100%) พร้อมเสียงเตือน Soft Alert
   - **การดำเนินการสำคัญ (ลบ/แก้ไขข้อมูล):** ยืนยันด้วย **SweetAlert2** Modal ขอบมนพรีเมี่ยม
   - **ปุ่มและสถานะ:** Active state ชัดเจน, Hover animation ลื่นไหล, Badge กำกับสถานะ (Draft, Active, Completed, Replicate)

## ผลที่ตามมา
- นักวิจัยใช้งานได้คล่องตัวแม้อยู่หน้ากล้องจุลทรรศน์หรือหน้าถังหมัก ลดความผิดพลาดในการป้อนข้อมูล
